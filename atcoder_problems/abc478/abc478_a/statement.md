# ABC478 A: Grapes

公式問題文をもとにした日本語の学習用記述です。原文は[AtCoderの問題ページ](https://atcoder.jp/contests/abc478/tasks/abc478_a)を参照してください。

## 問題

番号 `1` から `N` までの `N` 人と、`M` 粒のぶどうがあります。人 `1` から人 `N` まで順番に1粒ずつ配ります。人 `N` まで配ってぶどうが残っていれば、再び人 `1` から同じ順番で配ります。ぶどうがなくなるまで配ったとき、各人が受け取る粒数を求めてください。

## 制約

- `1 <= N <= 100`
- `1 <= M <= 10000`
- `N` と `M` は整数

## 入力

```text
N M
```

## 出力

人 `i` が受け取る粒数を、`i = 1` から `N` まで1行ずつ出力してください。

## 入力例 1

```text
3 5
```

## 出力例 1

```text
2
2
1
```

この例では、人 `1, 2, 3, 1, 2` の順に1粒ずつ配ります。
