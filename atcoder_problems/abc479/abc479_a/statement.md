# ABC479 A: Odd Index Sum

公式問題文をもとにした日本語の学習用記述です。原文は[AtCoderの問題ページ](https://atcoder.jp/contests/abc479/tasks/abc479_a)を参照してください。

## 問題

長さ `N` の整数列 `A = (A_1, A_2, ..., A_N)` が与えられます。列の先頭を1番目として、奇数番目にある要素の合計を求めてください。

## 制約

- 入力される値はすべて整数
- `1 <= N <= 100`
- `1 <= A_i <= 100`

## 入力

```text
N
A_1 A_2 ... A_N
```

## 出力

奇数番目にある要素の合計を出力してください。

## 入力例 1

```text
5
3 1 4 1 5
```

## 出力例 1

```text
12
```

この例では1番目、3番目、5番目の値を足します。
