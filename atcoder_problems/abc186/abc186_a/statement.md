# ABC186 A - Brick

公式問題文: https://atcoder.jp/contests/abc186/tasks/abc186_a

## 問題の目的

最大 `N` kg まで積めるトラックに、1個 `W` kg のレンガを最大何個積めるか求めてください。

## 入力

整数 `N` と `W` が空白区切りで与えられます。

## 制約

- `1 ≤ N, W ≤ 1000`
- `N` と `W` は整数

## 出力

積めるレンガの最大個数を整数で出力してください。

## サンプル

入力:

```text
10 3
```

出力:

```text
3
```

レンガ3個なら合計9 kg、4個なら12 kgになるため、最大3個です。

入力:

```text
1000 1
```

出力:

```text
1000
```
