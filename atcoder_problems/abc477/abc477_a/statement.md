# ABC477 A: Traffic Light

公式問題文をもとにした日本語の学習用記述です。原文は[AtCoderの問題ページ](https://atcoder.jp/contests/abc477/tasks/abc477_a)を参照してください。

## 問題

信号の色は `B`（青）、`Y`（黄）、`R`（赤）の順に変わり、この順序を繰り返します。現在の色を表す文字 `c` が与えられるので、次の色を出力してください。

## 制約

- `c` は `B`、`Y`、`R` のいずれか

## 入力

```text
c
```

## 出力

現在の色の次に変わる色を出力してください。

## 入力例 1

```text
B
```

## 出力例 1

```text
Y
```
